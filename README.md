# Philoloom — атлас философской мысли

**Philoloom** — независимый авторский проект: интерактивный справочник, объединяющий философские темы, мыслителей, исторические периоды и цитаты через проверяемые смысловые связи.

[Открыть атлас](https://mksddn.github.io/philoloom/) · [Сообщить об ошибке](https://github.com/mksddn/philoloom/issues) · [Предложить изменение](CONTRIBUTING.md)

## О проекте

Задача Philoloom — помогать ориентироваться в философии, не превращая её в набор изолированных определений. Каждая карточка кратко объясняет идею, содержит более развёрнутый материал и показывает связи с другими сущностями.

- Темы и направления философии.
- История философии и мыслители.
- Цитаты с внутренним реестром проверки происхождения.
- Перелинковка и поиск по самостоятельным страницам.

Материалы проходят редакционную проверку; наличие источника не означает, что каждая историческая интерпретация уже получила академическое рецензирование.

## Предложить дополнение

Проект принимает замечания, исправления фактических ошибок, новые материалы и предложения по развитию интерфейса через GitHub Issues и Pull Requests. Для начала прочитайте [правила участия](CONTRIBUTING.md) и [редакционные требования](docs/CONTENT_GUIDE.md).

Упоминания авторов, ссылки на первоисточники и корректная передача разных философских позиций важнее количества карточек. Внешние изменения проходят проверку перед включением в основную ветку.

## Как устроен репозиторий

| Путь | Назначение |
| --- | --- |
| `content/knowledge/` | Markdown-статьи, CSV-реестры и явные связи сущностей |
| `content/slugs.json` | Постоянные публичные URL для записей |
| `content/quote-provenance.json` | Проверка происхождения цитат |
| `content/image-manifest.json`, `content/optimized/` | Локальные изображения и адаптивные варианты |
| `site/` | Интерфейс, стили и статические ресурсы |
| `scripts/build.py` | Генератор статического сайта |
| `scripts/audit_content.py` | Аудит содержимого и связей |
| `tests/` | Регрессионные и визуальные проверки |
| `docs/` | Архитектура, редакционная политика и публикация |

Записи используют постоянные внутренние идентификаторы. Ссылки и отношения описаны в Markdown и CSV; публичные адреса задаются отдельно в `content/slugs.json`. Идентификаторы и существующие адреса нельзя произвольно менять — это может разорвать связи и внешние ссылки.

Сайт собирается в статические HTML-файлы, работает без сервера приложений и публикуется через GitHub Pages.

## Локальный запуск

Нужны Python 3.9+, Git LFS и, для удобства, `make`.

```bash
git clone https://github.com/mksddn/philoloom.git
cd philoloom
git lfs install --local
git lfs pull
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
make serve
```

Откройте http://localhost:8000. Команда создаёт папку `dist/` и запускает локальный HTTP-сервер. Для разовой сборки используйте `make build`, а перед PR — `make check` и `python3 scripts/audit_content.py --summary --strict`.

Правьте исходники, а не `dist/`: сборка создаёт его заново. Для работы с изображениями нужен Git LFS; некоторые источники изображений и внешние ссылки могут быть недоступны без интернета.
