# PhiloLoom

Личный философский справочник с оформлением в стиле Notion. Сайт собирается из Markdown и CSV в набор статических HTML-страниц. Доступ к Notion для сборки и просмотра не требуется.

## Требования

- Python 3.9 или новее с модулями `venv` и `pip`.
- `make` для коротких команд запуска; ниже приведены команды без него.

## Первый локальный запуск

Открой терминал в папке репозитория. Для текущего расположения на macOS:

```bash
cd /Users/mksddn/WORK/GIT/philoloom
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
make serve
```

Открой http://localhost:8000 в браузере. Терминал должен оставаться открытым. Для остановки сервера нажми **Ctrl+C**.

Установка зависимостей требует доступа к интернету. После установки сайт работает локально, но внешние ссылки по-прежнему ведут на другие сайты.

## Повторный запуск

В папке репозитория выполни:

```bash
source .venv/bin/activate
make serve
```

Команда `make serve` пересобирает сайт и запускает сервер на порту 8000. После изменения исходников останови сервер и выполни её снова, затем обнови страницу в браузере.

## Запуск без make

После установки зависимостей и активации `.venv`:

```bash
python3 scripts/build.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Если порт 8000 занят, замени его, например, на 8001 и открой http://localhost:8001.

## Только сборка

После активации `.venv`:

```bash
make build
```

Или без `make`:

```bash
python3 scripts/build.py
```

Результат находится в `dist/`. Эту папку можно разместить на статическом хостинге. Для локального просмотра используй HTTP-сервер: открытие HTML напрямую как файла не обеспечивает работу поиска.

## Где хранится содержимое

- `content/notion/` — исходный экспорт: Markdown-страницы, CSV с записями и связями, вложенные изображения.
- `site/style.css` — оформление сайта.
- `site/app.js` — поиск по справочнику.
- `scripts/build.py` — сборка страниц и поискового индекса.
- `requirements.txt` — зависимости сборки.
- `dist/` — сгенерированный сайт; исключён из Git.
- `.venv/` — локальное окружение Python; исключено из Git.

Редактируй исходники, а не файлы в `dist/`: сборка полностью заменяет эту папку. При изменении названий и связей согласованно обновляй соответствующие Markdown и CSV; идентификаторы в именах файлов используются для внутренних ссылок.

## Работа в облачной среде

После клонирования репозитория перейди в его папку и выполни те же команды установки и сборки. Путь `/Users/mksddn/WORK/GIT/philoloom` относится только к текущему компьютеру; в облаке используй путь к своему клону. Все исходные данные и настройки сборки находятся в репозитории. Node.js, локальные файлы вне репозитория и подключение к Notion не нужны.

## Ограничения экспорта

В архиве отсутствуют восемь PDF-заданий, на которые ссылаются записи. Они отмечены на сайте как отсутствующие в экспорте. Внешние материалы, доступные только по ссылкам, не скачиваются при сборке.


## Карточки, боковая панель и миниатюры

Нажатие на запись, внутреннюю ссылку или результат поиска открывает подробности в боковой панели. В ней доступны возврат, следующая запись и открытие на всю страницу. Закрыть панель можно крестиком, клавишей **Esc** или нажатием снаружи. Кнопки «Назад» и «Вперёд» браузера также работают. На узком экране панель занимает всю ширину.

Для истории философии, личностей и статей доступны представления «Таблица» и «Галерея». Нажатие на заголовок столбца сортирует таблицу. Изображения в тексте можно увеличить нажатием. Поиск открывается кнопкой или сочетанием **Ctrl+K / ⌘K**. При системной настройке уменьшения движения анимации отключаются.

Данные закладок хранятся в `content/link-previews.json`, скачанные миниатюры — в `content/previews/`. Обычная сборка использует этот кэш без сетевых запросов. Если изображение не удалось скачать, сайт пробует загрузить его по исходному адресу; при ошибке миниатюра скрывается. Некоторые исходные портреты также остаются внешними изображениями.

Чтобы обновить данные превью и скачать доступные изображения, активируй `.venv` и выполни:

```bash
python3 scripts/refresh_previews.py --download-images
make build
```

Обновление требует интернета и запрашивает только публичные ссылки, присутствующие в экспорте. Недоступные сайты не останавливают обновление: ранее сохранённые данные сохраняются. Сами статьи и страницы по ссылкам не копируются. Сайты без доступной миниатюры отображаются текстовыми закладками.
