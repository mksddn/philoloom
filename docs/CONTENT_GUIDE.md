# Редакционные правила

PhiloLoom — справочник, а не автоматическая реконструкция философских позиций. При обновлении статьи различай:
- **Первичный источник:** произведение или высказывание философа (с точной ссылкой на издание, раздел, страницу — если известны).
- **Интерпретация:** мнение исследователя с указанием автора и работы.
- **Редакторский текст:** собственное изложение и выводы, не выдаваемые за цитаты.

## Предлагаемая карточка качества (для будущих новых материалов)

```yaml
title: "Название темы"
kind: topic
sources:
  - author: "Автор"
    work: "Произведение"
    edition: "Издание или URL"
    locator: "Страница/раздел, если известен"
review_status: draft # draft | checked
reviewed_at: null # YYYY-MM-DD, только после проверки
```

Это **образец**, а не уже поддерживаемый формат импорта. Не добавляй YAML автоматически в существующий Notion-экспорт: генератор пока читает первую Markdown-строку как заголовок, и такая вставка может сломать сайт. Источники можно пока указывать непосредственно в тексте статьи; отдельная структурированная схема потребует доработки сборщика.

Запускай `python3 scripts/audit_content.py` для поиска потенциальных дубликатов и шаблонных записей. `--report <путь>` сохранит JSON; `--strict` превратит находки в ошибку для ручной редакционной проверки. Скрипт ничего не удаляет, не объединяет и не изменяет.

Публичность: все исходные Markdown и CSV в репозитории доступны читателям, даже если они не отображаются на сайте. Личные учебные заметки хранить **только отдельно**, вне публичного репозитория.
