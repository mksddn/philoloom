## Редакторские решения

- Оригинальные PDF и их текст не публикуются. В репозитории остаются только **указатели на источник и независимые аналитические выводы**.
- Точность цитат Витгенштейна и Хайдеггера по-прежнему **не подтверждена**. Источниковый реестр `content/quote-provenance.json` сохраняет им статус `paraphrase_review`; публичные комментарии под цитатами остаются выключенными.
- **Не переводить карточки в `ready`** только за совпадение содержания с конспектом. Для этого нужна сопоставимая проверка по самому философскому произведению и/или качественной академической работе.
- В остальных модулях корпуса присутствуют материалы по этике, религиоведению, искусству, политической философии и другим темам, для которых самостоятельные публикации ещё не созданы. Это **список областей для расширения**, а не призыв автоматически генерировать статьи.
