# PhiloLoom — реализация фирменного стиля

**Источник направления:** [BRAND_DIRECTION.md](BRAND_DIRECTION.md), PR #4.  
**Ветка:** `design/site-brand-rollout`, PR #5 (черновик; базовая ветка `design/approved-visual-direction`).  
**Статус:** минималистичный философский справочник, с исходной цитатой внутри Hero. До согласования владельцем ничего не сливать в `main`.

## Принципы текущей композиции

Ссылка на визуальный референс не означает необходимость буквально копировать его навигационную структуру: важны светотень, классический образ, типографика и музейный характер. **Не превращать философскую энциклопедию в продающую витрину.**

1. **Полноширинный Hero** — фон без рамки и карточки, два утверждённых художественных образа Рене Декарта (тёмный музейный и светлый мраморный) и один `h1` «Философия как искусство мышления». Под заголовком расположена исходная цитата Декарта с указанием автора. Никаких CTA, выдуманных подзаголовков и ссылок на разделы внутри Hero.
2. **Исходная цитата внутри Hero.** Под главным заголовком размещена дословная цитата Рене Декарта из оригинального Notion-экспорта: «Человеку, исследующему истину, необходимо хоть один раз в жизни усомниться во всех вещах». Текст извлекается из источника при сборке и не редактируется в Markdown.
3. **Три содержательных ресурсных блока** непосредственно под Hero: «Видео» (плейлисты из оригинала), «Библиотека» (исходные ссылки на журналы и библиотеки) и «Блог о философии» (исходный URL). Оформление повторяет компактный ряд редакционных элементов референса, без рекламных слоганов и избранных сущностей. В подвале их повторно не показываем.
4. **Единое меню разделов** после блока ресурсов: вкладки «Темы», «История философии», «Цитаты», «Личности». Их названия и адреса совпадают с реально существующими базами. Шапка содержит только текстовый PHILOLOOM, поиск и переключатель темы — **без второго меню**.
5. **Равноправный каталог** — без избранных тем, отдельной «коллекции» первых пяти карточек, маркетинговых заголовков и блока «О проекте». Режимы «Галерея / Список / Таблица» остаются для каждого раздела, изображения существующих записей не заменяются неподтверждёнными портретами.
6. **Связи между сущностями важнее декоративных переходов.** В детальных записях сохранены метаданные, прямые отношения, обратные ссылки и хлебные крошки. Ссылки на связанные страницы визуально различимы; никакие новые смысловые связи не придуманы.
7. **Внутренние страницы** остаются спокойными и функциональными, с режимом чтения, ограничением ширины строки, доступным текстом и обеими темами.

## Архитектурные ограничения

| Компонент | Инвариант |
| --- | --- |
| `content/notion/`, Markdown и CSV | Оригиналы неизменны, отсутствует редакционная персонализация |
| `scripts/build.py` | Генерация независимых статических HTML и `search.json` |
| `site/app.js` | Поиск, Ctrl/⌘+K, вкладки, сохранение вида, сортировка, боковые панели, чтение, темы |
| `site/style.css` | Нативный CSS, кириллические системные serif/sans; без новых зависимостей |
| `tests/test_site.py` | Наличие всех страниц, корректные связи и отсутствие личной учебной информации |
| `tests/visual_smoke.cjs` | Проверка десктопа 1440 px и мобильных 390/320 px в Chromium |
| `main` и GitHub Pages | Не изменяются до явного согласия |

Секциям при отсутствии JavaScript соответствует полноценный HTML с заголовками и прямыми ссылками. После включения JS вкладки скрывают неактивные разделы; повторяющиеся визуальные заголовки разделов не показываются, но остаются доступны скринридерам. Диалоги работают с клавиатуры и Escape. Таблицы прокручиваются по горизонтали внутри своих областей.

## Изображения Hero и темы

В Hero используются **две утверждённые пользователем иллюстрации Рене Декарта**, созданные специально для PhiloLoom. Это **художественные интерпретации**, а не фотографии исторически подтверждённых бюстов. Используем точное описание в доступной подписи изображения: «Художественный образ Рене Декарта», без ложной музейной атрибуции.

| Тема | Изображение | Атмосфера |
| --- | --- | --- |
| Тёмная | `site/assets/descartes-hero-dark.webp` | Тёмный зал, мраморный бюст, контрастная светотень |
| Светлая | `site/assets/descartes-hero-light.webp` | Солнечная галерея, тёплый белый камень |

В сборке оба WebP попадают в `dist/ui/`. Исходники сгенерированных композиций сохранены в истории чата; в Git добавлены **локальные оптимизированные 1440×810 WebP** (~28 КБ каждый). Для двух конкретных файлов в `.gitattributes` сделано исключение из Git LFS, так как это небольшие ресурсы интерфейса; существующие LFS-файлы контента не затронуты.

CSS через `html[data-theme="light"]` переключает **не только изображение**, но и цвета шапки, заголовка, цитаты, декоративных линий, градиента и фона. Рендер выполняется из локального файла без внешних запросов и без замены текста Hero. На мобильном изображение занимает верхнюю часть композиции, градиент защищает текст и подпись, портрет кадрируется отдельно. Исходная цитата и весь каталог остаются неизменны.


## Приёмка

- Hero занимает всю ширину viewport (никаких карточных рамок), цитата Декарта находится внутри него и выводится только один раз.
- Ровно одно меню вкладок соответствует четырём разделам без дублирования в шапке.
- Нет избранных тем, подборок, блока «О проекте», лишних CTA и рекламной лексики; внутри Hero сохранена оригинальная цитата, а три ресурсных блока находятся непосредственно под ним.
- Все исходные сущности доступны через каталог и внутренние ссылки; SEO-страницы существуют без JS.
- Сохраняются поиск, три вида каталога, сортировка, темы, диалоги, режим чтения, связи и исходные 11 ссылок на видеоматериалы/библиотеки.
- Обе темы используют собственное изображение, цветовую палитру, градиенты и читаемую цитату; проверяются адаптивное кадрирование и отсутствие переполнения на 320/390/1440 px.
- Контрастные состояния `focus-visible`, `prefers-reduced-motion`, доступные подписи иллюстраций.
- Запуски `make check` и `node tests/visual_smoke.cjs` проверяют функциональность и адаптивность без генерации скриншотов — визуальное ревью проводится владельцем в локальном запуске.

**Никакого слияния в main до согласования.**
