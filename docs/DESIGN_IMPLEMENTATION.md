# Реализация визуального оформления PhiloLoom

**Основное направление:** [BRAND_DIRECTION.md](BRAND_DIRECTION.md).  
**Изменения:** ветка `design/compact-hero-no-header`.

## Композиция

- Шапка удалена. Главная страница имеет единственный `h1` с названием **PhiloLoom** и продолжением «Философия как искусство мышления»; у внутренних страниц остаются собственные заголовки.
- Полноширинный Hero стал ниже. Художественные изображения Декарта кадрируются с приоритетом верхней части, чтобы голова была видна. Ширина заголовка и дословной цитаты увеличена на широких экранах.
- Поиск располагается справа от вкладок каталога и остаётся видимым на телефоне при горизонтальной прокрутке вкладок. На внутренних страницах кнопка поиска размещена около хлебных крошек. Горячая клавиша Ctrl/⌘+K сохраняется.
- Тему определяет только `prefers-color-scheme`. Внешний переключатель темы, пользовательские настройки чтения, их обработчики и хранение удалены.
- Все разделы, три режима каталога, связи, видео, библиотека, блог и источник цитаты сохранены.

## Ограничения

- Файлы `content/notion/` не редактируются, философский контент не пересказывается.
- Стек остаётся прежним: Python-генератор, статический HTML, CSS, JavaScript и GitHub Actions без новых зависимостей.
- Проверки на 1440, 390 и 320 px включают компактный Hero, темы устройства, навигацию, поиск, отсутствие прокрутки страницы по горизонтали и отсутствие режима чтения.
- После проверки CI и PR изменения можно объединять в `main`; уже настроенный деплой запускается для `main`.
