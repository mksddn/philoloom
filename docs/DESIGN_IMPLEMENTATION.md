# PhiloLoom — реализация фирменного стиля

**Источник направления:** [BRAND_DIRECTION.md](BRAND_DIRECTION.md), PR #4.  
**Ветка:** `design/site-brand-rollout`, PR #5 (черновик; базовая ветка `design/approved-visual-direction`).  
**Статус:** третья визуальная итерация, с приоритетом философского справочника перед лендингом. До согласования владельцем ничего не сливать в `main`.

## Принципы текущей композиции

Ссылка на визуальный референс не означает необходимость буквально копировать его навигационную структуру: важны светотень, классический образ, типографика и музейный характер. **Не превращать философскую энциклопедию в продающую витрину.**

1. **Полноширинный Hero** — фон без рамки и карточки, композиция со скульптурой Марка Аврелия, один `h1` «Философия как искусство мышления» и короткое фактическое пояснение. Никаких CTA-кнопок и ссылок на разделы внутри Hero.
2. **Единое меню разделов** сразу под Hero: вкладки «Темы», «История философии», «Цитаты», «Личности». Их названия и адреса совпадают с реально существующими базами. Шапка содержит только текстовый PHILOLOOM, поиск и переключатель темы — **без второго меню**.
3. **Равноправный каталог** — без избранных тем, отдельной «коллекции» первых пяти карточек, маркетинговых заголовков и блока «О проекте». Режимы «Галерея / Список / Таблица» остаются для каждого раздела, изображения существующих записей не заменяются неподтверждёнными портретами.
4. **Связи между сущностями важнее декоративных переходов.** В детальных записях сохранены метаданные, прямые отношения, обратные ссылки и хлебные крошки. Ссылки на связанные страницы визуально различимы; никакие новые смысловые связи не придуманы.
5. **Дополнительные материалы** из исходной домашней страницы сохранены: видео, библиотеки, блог. Два существующих диалога теперь открываются из лаконичных текстовых ссылок в подвале главной, а не из крупных рекламных карточек.
6. **Внутренние страницы** остаются спокойными и функциональными, с режимом чтения, ограничением ширины строки, доступным текстом и обеими темами.

## Архитектурные ограничения

| Компонент | Инвариант |
| --- | --- |
| `content/notion/`, Markdown и CSV | Оригиналы неизменны, отсутствует редакционная персонализация |
| `scripts/build.py` | Генерация независимых статических HTML и `search.json` |
| `site/app.js` | Поиск, Ctrl/⌘+K, вкладки, сохранение вида, сортировка, боковые панели, чтение, темы |
| `site/style.css` | Нативный CSS, кириллические системные serif/sans; без новых зависимостей |
| `tests/test_site.py` | Наличие всех страниц, корректные связи и отсутствие личной учебной информации |
| `tests/visual_smoke.cjs` | Проверка десктопа 1440 px и мобильных 390/320 px в Chromium |
| `main` и GitHub Pages | Не изменяются до явного согласия |

Секциям при отсутствии JavaScript соответствует полноценный HTML с заголовками и прямыми ссылками. После включения JS вкладки скрывают неактивные разделы; повторяющиеся визуальные заголовки разделов не показываются, но остаются доступны скринридерам. Диалоги работают с клавиатуры и Escape. Таблицы прокручиваются по горизонтали внутри своих областей.

## Приёмка

- Hero занимает всю ширину viewport (никаких карточных рамок).
- Ровно одно меню вкладок соответствует четырём разделам без дублирования в шапке.
- Нет избранных тем, подборок, блока «О проекте», лишних CTA и рекламной лексики.
- Все исходные сущности доступны через каталог и внутренние ссылки; SEO-страницы существуют без JS.
- Сохраняются поиск, три вида каталога, сортировка, темы, диалоги, режим чтения и связи.
- Контрастные состояния `focus-visible`, `prefers-reduced-motion`, отсутствие переполнения на 320/390/1440 px.
- Запуски `make check` и `node tests/visual_smoke.cjs` проходят; артефакт GitHub Actions `philoloom-visual-review` содержит скриншоты.

**Никакого слияния в main до согласования.**
