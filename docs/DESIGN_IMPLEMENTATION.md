# PhiloLoom — план и реализация утверждённого визуального стиля

**Основание:** [BRAND_DIRECTION.md](BRAND_DIRECTION.md), PR #4, 12.11.2026.  
**Ветка реализации:** `design/site-brand-rollout` (от `design/approved-visual-direction`).  
**Границы:** только интерфейс, сборка HTML и проверки; исходные `content/notion/`, CSV, поисковые записи и философские материалы не изменяются. Создание логотипа исключено.

## 1. Что уже работает и должно остаться

| Слой | Текущая архитектура | Инвариант |
| --- | --- | --- |
| Контент | `content/notion/` → `scripts/build.py` → статические страницы в `dist/` | Ни одна исходная запись/связь не редактируется |
| Навигация | Четыре раздела, якорные URL, переключаемые вкладки | При отключённом JS все разделы остаются в HTML |
| Каталог | «Галерея», «Список», «Таблица»; сохранение вида; сортировка | Не менять идентификаторы страниц или названия групп |
| Поиск | Локальный `search.json`, диалог, Ctrl/⌘+K | Ссылки и индекс остаются доступными, без сторонней поисковой службы |
| Детальные страницы | Отдельные HTML, хлебные крошки, связи/обратные ссылки | Полезный статический HTML индексируется поисковиками |
| Чтение | Размер и ширина текста, полноэкранная страница и боковая панель | Читабельность, клавиатурная навигация, работа без JS |
| Медиа | Оптимизированные WebP для существующего экспортированного контента | Не менять оригинальные вложения или их контрольные суммы |

## 2. Последовательность внедрения

1. **Дизайн-токены и типографика.** На `site/style.css` закрепить угольный фон, графитовые поверхности, каменные оттенки и дозированную бронзу. Системные serif/sans-стэки поддерживают кириллицу без сетевого запроса шрифтов.
2. **Тёмная редакционная обложка.** В `scripts/build.py` добавить крупный музейный образ, асимметричную иерархию, позиционирование, переход к каталогу и доступное указание авторства изображения. Название PhiloLoom — только текст, без логотипа.
3. **Каталог и внутренние страницы.** Сохранить четыре секции и три представления; оформить их как редакционную коллекцию. На страницах чтения использовать ровный фон, ширину около 72 знаков, умеренный интерлиньяж и доступные метаданные.
4. **Тема и адаптивность.** Тёмная тема по умолчанию, полноценная светлая по переключателю с сохранением выбора; точки адаптации 850, 650 и 360 px. Нативный горизонтальный скролл таблиц.
5. **Проверки.** Запуск существующих Python-тестов, автоматизированный браузерный smoke в Chromium на 1440/390/320 px, поиск, вкладки, карточки, панель, ресурсы и режим чтения; выкладка скриншотов как артефактов PR.
6. **Ревью.** PR в базовую ветку с направлением дизайна; отдельное согласование, до слияния в `main` не переходить.

## 3. Принятые решения

- Подключение UI-библиотеки, сборщика фронтенда, веб-шрифтов и 3D не требуется. Сайт остаётся Python + CSS + vanilla JS.
- Обложка **не содержит придуманной цитаты**: позиционирование — интерфейсный/редакторский текст; цитата Рене Декарта выводится из существующего источника без изменения.
- Изображение первого экрана: **мраморный бюст Зенона Китийского**, Римская копия греческого оригинала, собрание Ny Carlsberg Glyptotek, фото **Marie-Lan Nguyen**, лицензия **CC BY 4.0**, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Zeno_of_Citium_Ny_Carlsberg_Glyptotek_IN606.jpg). На сайте показаны атрибуция, источник и лицензия. Изображение загружается как адаптированная по ширине миниатюра (800 px), с CSS-деградацией до тёмного фона, если внешний ресурс недоступен.
- **Ограничение первой версии:** герой пока загружается с Wikimedia, а не из локального WebP. Для полной независимости от внешнего хоста позже нужно добавить файл из проверенного лицензированного источника в оптимизатор, обновить `image-manifest.json` и заново проверить размер и свойства изображения.
- Для карточек тем применены абстрактные архитектурные мотивы без исторических атрибуций и без имитации логотипа. Картинки, уже встроенные в оригинальные страницы, остаются прежними.
- Персональные отметки знания, задания и прогресс остаются исключёнными из публичного UI; правила `docs/CONTENT_GUIDE.md` не меняются.

## 4. Порог качества и критерии приёмки

- **Доступность:** видимый `:focus-visible`, `skip`-ссылка, реальные подписи и кнопки, сохранённые нативные диалоги, клавиатурные вкладки, `prefers-reduced-motion`. Токены текстовых цветов имеют контраст не менее 6:1 против основного фона в обеих темах (для конкретных блоков нужна визуальная проверка).
- **Чтение:** в длинных статьях нет фоновых скульптур и тяжёлых графических эффектов; основной текст 16–17 px, высота строки около 1.8, ширина текста ограничена.
- **Производительность:** одна приоритетная обложка на главной, без новых JS-библиотек в production, без удалённых шрифтов, существующая оптимизация контентных изображений не затронута.
- **SEO:** статические `h1` и `article`, метаописания, отдельные постоянные URL, реальные `a href`; всё чтение доступно без выполнения JS.
- **Адаптивность:** отсутствие горизонтального переполнения на 320, 390 и 1440 px; адаптивный герой; карточки и панели не блокируют доступ к основному тексту.
- **Регрессии:** `make check` и `node tests/visual_smoke.cjs`; скриншоты хранятся в GitHub Actions artifact `philoloom-visual-review`.

### Команды для локальной проверки

```bash
make check
npm install --no-save playwright@1.56.1
npx playwright install chromium
node tests/visual_smoke.cjs
```

При проверке библиотеки в CI отдельно выполняются Linux-зависимости браузера; `npm` нужен только для тестов, **не для сборки или работы сайта**.

## 5. Что необходимо посмотреть перед согласованием PR

На широком экране — баланс текста и бюста, источник изображения, вкладки, скролл и светлая тема. На телефоне — обрезку бюста, перенос названия, отсутствие горизонтального скролла, панель подробностей и режим чтения. Нужна также ручная оценка контраста кнопок в состояниях hover/focus и проверки с медленным интернетом. CI предоставляет скриншоты, но не заменяет субъективное согласование художественного результата.

**Публикация:** никаких автоматических слияний с `main`; PR остаётся на ревью.
