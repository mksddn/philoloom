# Редакционный слой — новые записи без изменения экспорта Notion

Исходный каталог `content/notion/` сохраняется как архив. Новые публичные записи размещаются в `content/editorial/pages/<stable-id>.md` и описываются реестром `content/editorial/entries.json`. При сборке все данные объединяются без ручного изменения CSV Notion.

## Добавление материала

Подготовь Markdown-файл только с текстом статьи (без первого заголовка `#`). Вступление на 100–650 символов должно **объяснять суть мысли**, а не классифицировать понятие. Дальше — основной текст (от 250 символов), а для темы или исторической эпохи — отдельный раздел `## Источники и дальнейшее чтение` с реальной библиографией.

```bash
python scripts/new_entry.py --group 'Темы' --title 'Этика' --slug etika \
  --body-file /tmp/etika.md \
  --relation 'Личности=d5303c3cb5d8405b8915abd0d9074c9f'
```

Для биографий используй `--group 'Личности' --birth 1724 --death 1804` (смерть можно не указывать для живущих философов). Поддерживается `--group 'История философии'`. Повторяй `--relation FIELD=ID` для дополнительных существующих публичных связей; неизвестные и личные ID отклоняются. `--dry-run` проверяет запрос без изменения файлов.

Скрипт генерирует устойчивый ID, Markdown, запись в редакционном реестре и канонический URL в `content/slugs.json`. Исходные файлы Notion не меняются. После добавления запускай `make check` и `python scripts/audit_content.py --strict --summary`. Проверки структуры не заменяют академическую сверку.

## Будущий собственный домен

Пока каноническая база — `https://mksddn.github.io/philoloom/`. Для предварительной сборки с новой базой:

```bash
PHILOLOOM_SITE_URL=https://philoloom.ru/ make build
```

Базовый URL определяет canonical, sitemap.xml, robots.txt и старые перенаправления. При корневом домене для GitHub Pages создаётся файл `CNAME`. В деплой-воркфлоу учитывается репозиторная переменная `PHILOLOOM_SITE_URL`, но **переезд не активирован**. После приобретения домена потребуется настроить DNS, GitHub Pages Custom Domain, HTTPS и проверить индексацию. Не меняй переменную до готовности DNS.

## Ограничения

Редакторские добавления не редактируют прежние статьи экспорта. Для изменения существующих оригиналов нужна отдельная система версионированных правок. Новые связи в графе автоматически становятся только структурными отношениями; «развивает» или «критикует» требуют отдельного подтверждённого источника.
