# Карта философских знаний — проектное направление

## Задача

Создать отдельный, необязательный способ навигации по PhiloLoom: интерактивную карту понятий, мыслителей, направлений и исторических эпох. Существующее лаконичное оформление сайта сохранить, а карту открыть по отдельной ссылке, не заменяя основной справочник.

## Основные принципы

- **Источник истины:** существующие Markdown и CSV, идентификаторы Notion и явные связи. Нельзя автоматически объявлять смысловые связи доказанными.
- **Модель:** узел с `id`, `label`, `type`, `url`, `era?`; ребро с `source`, `target`, `relation`, `provenance`. Для каждой новой связи нужен источник (явная связь CSV, первоисточник или ручное редакторское подтверждение).
- **Публичность:** никаких персональных отметок освоения знаний, приватных заметок или учебной статистики.
- **Визуальный слой:** спокойная цветовая палитра, минимум визуального шума, управляемая камера, подсветка соседей, поиск и фильтр по типу/эпохе.
- **Доступность:** список/2D альтернатива, поддержка клавиатуры, `prefers-reduced-motion`, понятные подписи, производительный режим для мобильных устройств.
- **Производительность:** лениво загружаемый 3D-модуль, лёгкая JSON-модель, отложенная подгрузка подписей. Основной статический сайт не должен зависеть от WebGL.
- **Навигация:** клик по узлу ведёт на существующую страницу PhiloLoom.

## Очередность

1. Экспортировать граф из **уже явных** связей и проверить обратные ссылки; без предположительных зависимостей.
2. Сделать читаемую 2D-карту, оценить количество узлов, плотность графа и полезность навигации.
3. Добавить по желанию 3D-режим (например, Three.js или 3d-force-graph) с теми же данными, не меняя канонический контент.
4. Отдельно рассмотреть ручное редактирование типов связей: «влиял на», «критиковал», «развивал», «относится к эпохе», «связан с понятием».

**Статус:** проектный документ. Никакая 3D-визуализация пока не реализована.
