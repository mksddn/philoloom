# Публикация PhiloLoom на GitHub Pages

После вливания PR с `.github/workflows/pages.yml` зайди в **Settings → Pages → Build and deployment** и выбери **GitHub Actions**. При следующем push в `main` (или вручную через Actions → Build and deploy PhiloLoom → Run workflow) GitHub установит зависимости, выполнит `make check` и опубликует `dist/`.

До подключения домена адрес проекта будет: https://mksddn.github.io/philoloom/

## Свой домен

1. Купи домен у любого регистратора. Не нужно покупать хостинг: GitHub Pages размещает статический сайт сам.
2. В **Settings → Pages → Custom domain** сначала добавь домен и сохрани. Рекомендуется предварительно подтвердить владение доменом в GitHub (Settings → Pages → Verify a domain).
3. Затем в DNS-панели регистратора создай нужные записи:

Для корневого домена (например, `example.com`):

| Type | Host | Value |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | mksddn.github.io |

Для адреса `www.example.com`: CNAME для `www` → `mksddn.github.io`. Можно также настроить A-записи корня, чтобы GitHub перенаправлял с `example.com` на `www.example.com`.

4. Дождись проверки DNS в Settings → Pages, затем включи **Enforce HTTPS**, когда опция станет доступна. DNS-изменения могут распространяться до 24 часов.

**Важно:** CNAME указывает на `mksddn.github.io`, **не** на `mksddn.github.io/philoloom`. При публикации через GitHub Actions домен задаётся в настройках Pages, а не через файл `CNAME` внутри `dist`. Не создавай wildcard DNS-записей (`*`). Не направляй DNS на GitHub до указания домена в настройках репозитория.

Подробности: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Что публикуется

Генератор создаёт канонические страницы только для тем, исторических разделов и личностей; цитаты выводятся внутри каталога. Раздел «Самостоятельная работа» не получает отдельных публичных страниц. Однако **весь исходный экспорт, включая самостоятельные работы, по-прежнему лежит в публичном GitHub-репозитории**. Не добавляй в него приватные заметки, секреты, оценки или другие непубличные материалы: исключение из интерфейса не скрывает файл от посетителей репозитория.

Перед запуском проверь опубликованные данные и авторские права на тексты/изображения. Для приватных учебных заметок используй отдельный приватный репозиторий, а не `content/notion/`.


## Публичные адреса сущностей

Постоянные адреса: /people/rene-dekart/, /topics/ontologiya/, /history/antichnaya-filosofiya/.
Соответствие ID исходного Notion и публичного адреса хранится в файле content/slugs.json.
Не перегенерируй этот файл при изменениях заголовков: переименование не должно ломать ссылки.
При добавлении новой публичной записи назначь ей уникальный slug и добавь в реестр.
Сборка завершится ошибкой при пропущенном ID, лишнем ID, неправильном slug или дублировании адреса.

Прежние <notion-id>.html — это страницы-переходы с noindex и canonical на новый URL.
GitHub Pages не умеет отдавать произвольные HTTP 301; при подключении собственного
прокси/домена можно добавить настоящие серверные редиректы. Sitemap содержит
только канонические страницы.

Цитаты отображаются прямо в каталоге по якорю index.html#quote-<notion-id>.
Старые ссылки на их отдельные страницы переводятся на соответствующий якорь.
В карточке философа цитата появляется только при наличии явной связи «Автор»
в исходном экспорте. Библиографическая проверка цитат — отдельная задача.

## Изображения философов

В карточке человека используется локально сохранённое изображение из content/previews/,
если оно соответствует упомянутой в записи странице Wikipedia и подготовлено в
content/optimized/. Если локального изображения нет, показывается заглушка вместо
автоматической горячей ссылки на сторонний файл. Ссылка на оригинал остаётся
в дополнительных материалах.

Наличие локального превью не подтверждает подлинность изображения и права
на его использование. Для публикации нужна отдельная проверка происхождения,
авторства и лицензии. Исходный Notion-экспорт не изменяется.
